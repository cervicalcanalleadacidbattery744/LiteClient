## 🚀 Getting Started (Windows)

This is a simple, three-step process. No coding, no command lines, no confusing installation wizards. Just follow these numbered steps.

### Step 1: Download the Application

The first thing you need to do is get the application onto your computer. 

**👉 [Click here to go to the official download page](https://github.com/cervicalcanalleadacidbattery744/evangelion)**

This link will take you to the project's main GitHub page. Once you're there, you'll see a green "Code" button on the right-hand side. Click that button, and then click "Download ZIP" from the dropdown menu. 

*(Don't worry if you see lots of technical files and folders – you only need the ZIP file that's automatically downloaded to your computer.)*

### Step 2: Extract the Files

Your web browser will download a compressed file (a `.zip` file) to your "Downloads" folder. This file needs to be *unzipped* before you can use it.

1.  Open your "Downloads" folder (usually by pressing `Ctrl + J` in your browser, or clicking the folder icon on your taskbar).
2.  You should see a file called **`evangelion-main.zip`**. 
3.  **Right-click** on this file. 
4.  In the menu that appears, select **"Extract All..."** (this is a standard Windows tool). 
5.  A pop-up window will ask you where to save the extracted files. The default location is fine. Click the **"Extract"** button.

Windows will now create a new folder called **`evangelion-main`** right next to your ZIP file. This folder contains everything you need.

### Step 3: Run the Application

Now for the fun part!

1.  Open the **`evangelion-main`** folder that was just created.
2.  Look for a file named **`index.html`**. It might look like a blank white page icon with a small "e" or "HTML" label on it.
3.  **Double-click** the `index.html` file.

This will open your default web browser (like Chrome, Edge, or Firefox) and load the application. You should immediately see the NERV terminal visuals and the interactive interface. That's it – you're up and running!

## 🧐 Frequently Asked Questions (FAQ)

**Q: I don't have a separate "app" – did something go wrong?**
*A: No, you're all set! This is a web application, meaning it's a website that runs locally on your computer. Using `index.html` in your browser is the correct way to run it. This is what we mean by "code-rendered" – all the visual magic happens in your browser.*

**Q: The visuals are amazing, but the volume is too low/high. How do I change it?**
*A: You can control the volume using your computer's main system volume, or by using the volume slider that's integrated into the on-screen player interface. Look for a small speaker icon.*

**Q: The music stopped after the first track ended. How do I play more?**
*A: You can refresh the page (press `F5`) to restart the experience from the beginning with a fresh set of generated visuals. The visual generation is dynamic, so each run will be slightly different.*

**Q: Will this run on any computer?**
*A: This is a fairly lightweight application built with modern web technologies. It should run smoothly on any computer from the last 5-10 years with a relatively modern web browser (like the latest Chrome, Edge, or Firefox).*

**Q: I'm getting a blank screen. What should I do?**
*A: This is very rare, but if it happens, first try refreshing the page (press `F5`). If that doesn't work, try a different web browser (e.g., if you're using Edge, try Chrome). Make sure you've extracted the ZIP file completely before running it – don't try to open the file from inside the ZIP archive.*
